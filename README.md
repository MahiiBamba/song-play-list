# **Java Song Playlist Application**

## **Project Description**
This Java application utilizes Java's built-in **LinkedList** framework to manage a song playlist. It allows users to perform various operations such as adding, removing, and displaying songs in the playlist.

## **Features**
- **Add Songs**: Insert new songs into the playlist.
- **Remove Songs**: Delete songs from the playlist.
- **Display Playlist**: Show all songs currently in the playlist.
- **Navigate Playlist**: Move through the playlist to play songs.

## **Getting Started**

### **Prerequisites**
- **Java Development Kit (JDK)**: Ensure that JDK 8 or later is installed on your system.

### **Installation**
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/MahiiBamba/song-play-list.git
   ```
2. **Navigate to the Project Directory**:
   ```bash
   cd song-play-list
   ```
3. **Compile the Java Files**:
   ```bash
   javac *.java
   ```
4. **Run the Application**:
   ```bash
   java MainFile
   ```

## **Usage**
Upon running the application, you can interact with the playlist through the console interface. Follow the on-screen prompts to add, remove, or navigate through songs in your playlist.
